# TypeScript Assignment

## Assignment Overview

This assignment covers some fundamental TypeScript concepts and practical coding exercises. The goal is to understand TypeScript functions, type safety, generics, interfaces, object-oriented programming, and asynchronous operations through hands-on examples.

## Topics Covered

The assignment includes the following exercises:

1. **Function with Default Parameters:** Created a multiplication function with a default multiplier value.
2. **Union Types and Type Narrowing:** Used `string | number | boolean` with `typeof` to process different types of input.
3. **Readonly Tuples:** Used a readonly tuple to store and format geographic coordinates.
4. **Generics:** Created a reusable function to concatenate multiple arrays.
5. **Interfaces and Filtering:** Used an interface to define course structures and filtered published courses based on student numbers.
6. **Generic Functions with Keyof:** Created a function to extract specific property values from an array of objects.
7. **Classes and Inheritance:** Practiced OOP concepts using `Employee` and `Manager` classes with `protected` and `private` properties.
8. **Async/Await and Promises:** Created an asynchronous age validation function using Promises and async/await.
